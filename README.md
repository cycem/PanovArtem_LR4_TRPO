# Массажный салон — WPF-приложение

Приложение для записи клиентов в массажный салон. Пользователь смотрит список массажей и массажистов и записывается на сеанс. Может просматривать список своих записей. Администратор просматривает, редактирует и удаляет записи.

## Установка

1. Клонируйте репозиторий:
   git clone https://github.com/cycem/PanovArtem_LR4_TRPO.git
2. Установите SQL Server Express и создайте базу данных MassageSalon.
3. Откройте файл massageSalon.sln в Visual Studio.
4. В файле App.config в строке подключения укажите имя вашего сервера в параметре data source.

## Использование

- Новый пользователь нажимает «Создать учетную запись» и заполняет форму. Пароль не короче 8 символов.
- После входа обычный пользователь попадает на главную страницу: смотрит услуги и массажистов, выбирает массаж, массажиста, кабинет, дату и время и нажимает «Записаться».
- Администратор попадает на страницу администратора: выбирает запись в таблице, меняет данные и нажимает «Сохранить» или «Удалить».
- Кнопка «Выйти» возвращает на окно авторизации.

## Структура проекта

- Windows — главное окно с Frame для навигации между страницами
- Pages — страницы: LoginPage, RegistrationPage, MainPage, AdminPage
- Entities — модель базы данных (Entity Framework)
- App.xaml, App.xaml.cs — запуск приложения, общий контекст БД и текущий пользователь
- App.config — строка подключения к базе данных

## Данные

База данных MassageSalon (SQL Server), таблицы: Users, Roles, Masseurs, Services, Rooms, Appointments, Payments.  Чтобы создать администратора, измените RoleID на 1 у нужного пользователя в таблице Users.
